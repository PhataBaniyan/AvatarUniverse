# AvatarUniverse v0.1.0 — First Release

## Includes

- Four base elements (Air, Water, Earth, Fire) with 100+ abilities,
  plus sub-arts: Ice, Plant, Blood, Metal, Lava, Lightning, Combustion
- Click/sneak bending with hotbar binds and bending board
- Time mastery: sub-elements unlock automatically as you play
- Player-friendly commands — no OP needed for choose/bind/display;
  operators keep add/reload

## Install

1. NeoForge 1.21.1 + Java 21
2. Put the JAR in `mods/`
3. `/au choose water` (or your element) and bend
