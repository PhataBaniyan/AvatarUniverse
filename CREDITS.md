## Bending sources

Ability mechanics in this mod are reimplementations written natively for
NeoForge — no Bukkit code is used or included. The designs take inspiration
from the following open-source Bukkit plugins:

- **ProjectKorra** — <https://github.com/ProjectKorra/ProjectKorra>
  (LGPL-2.1) — core bending model: elements, slot-based abilities,
  TempBlock-style block restoration, water/earth sourcing, passives,
  and the `/bending` command structure.
- **ProjectAvatar** — ability design reference for several fire/air abilities.
- **ProjectAddons** (by Simplicitee) — extra ability mechanics.
- **JedCore** (jedk1, and the plushmonkey / Aztlon / CozmycDev forks) —
  addon abilities (e.g. FireSki, AirPunch, ElementSphere) and the
  bending-board concept.
- **Hyperion** — ability design reference.

All in-game description and usage text (`AbilityCodex.java`) is written
originally for this project.
